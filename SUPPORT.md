# Support

Search the [documentation](docs/README.md) and existing
[issues](https://github.com/HUSAM-07/orqara/issues) first. If the problem remains, open the matching
[issue form](https://github.com/HUSAM-07/orqara/issues/new/choose).

Include the Orqara version, operating system, agent provider, reproduction steps, and sanitized raw
logs. Use private vulnerability reporting for security problems.
